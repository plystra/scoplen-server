# Security policy

Report suspected vulnerabilities privately to `scoplen-security@plystra.com`. Do not open a
public issue or include credentials, private keys, setup links, customer data, or deployment
details in a report that is not addressed to the security contact.

The current repository is an exploration baseline. The first-run material and listener are not a
complete production deployment until the applicable roadmap gates, deployment checks, and
independent security review are complete.
